## 2. Installing Verified Open-Source Skills via Official Skills CLI

YouTube Agent Studio v3.0 uses the official **Skills CLI** (`npx -y skills add <repo>`) to install external skills into Claude Code or OpenAI Codex environments without polluting the core distribution repository.

### For Claude Code:
```bash
# Install JakeB-5/motion-graphic-skill (MIT)
npx -y skills add JakeB-5/motion-graphic-skill

# Install haidrrrry/claude-remotion-skill (MIT)
npx -y skills add haidrrrry/claude-remotion-skill
```

### For Codex / Custom Skills Directory:
```bash
# Install directly to local project skills directory
npx -y skills add JakeB-5/motion-graphic-skill --copy
npx -y skills add haidrrrry/claude-remotion-skill --copy
```

## 3. How the Native Browser Motion Engine Extends These Skills

While external motion skills often focus on prompt templates or client-side playback, YouTube Agent Studio v3.0 provides the **missing production bridge**:

1. **Deterministic Frame Server (`shared/scripts/browser_motion.py`)**:
   - Takes any HTML/CSS/Canvas animation generated by `JakeB-5/motion-graphic-skill` or Remotion and feeds it frame-by-frame through headless Chrome or Edge at exact 30 FPS.
   - Eliminates stutter, dropped frames, and hardware variance.

2. **Broadcast Encoding & Transparency**:
   - Encodes frame sequences directly to Full HD MP4 (`yuv420p`) or Apple ProRes 4444 (`yuva444p10le`) with true alpha transparency for NLE overlays.

3. **Multi-Track OpenTimelineIO Integration (`shared/scripts/otio_export.py`)**:
   - Inserts generated motion overlays onto Track `V3` in `.otio` and `.edl` timelines above base B-roll footage.

# YouTube Platform Chapter Requirements

To enable video scrubber chapters and Google "Key Moments" search indexing, a description must satisfy:
1. **00:00 (or 0:00) First Entry**: The very first timestamp line must start at zero.
2. **Minimum 3 Chapters**: Fewer than 3 timestamps will not render as chapters.
3. **Minimum 10 Seconds Duration**: Every chapter must be at least 10 seconds long before the next chapter begins.
4. **Ascending Order**: Timestamps must be strictly chronological.

Format example:
```
00:00 Introduction
01:15 The 3 Signs of Emotional Abuse
04:30 Setting Psychological Boundaries
08:15 Seeking Professional Help
```
